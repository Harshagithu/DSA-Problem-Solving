4 rules to solve any pattern based problems in the world :-
===========================================================

1. For the outer loop focus on the number of rows.
2. For the inner loop focus on the number of cols and connect some where to the rows.
3. Print them inside the inner loop.
4. Observe Symmetry (optional).

Pattern 7 :- (Pyramid Pattern)
============

n=4

      *      
    * * *    
  * * * * *   
* * * * * * *

for(int i=1;i<=n;i++)
{
   for(int j=1;j<=(n-i+1);j++)
      {
         sop(" ");
      }
   for(int j=1;j<=(2*i-1);j++)
      {
         sop("*");
      }
   for(int j=1;j<=(n-i+1);j++)
      {
         sop(" ");
      }
   sopln();
}

Pattern 10 :- (Half Diamond Pattern)
============

n=4

*
**
***
****
***
**
*

for(int i=1;i<=(2*n-1);i++)
{
   int stars=i;
   if(i>n) stars=(2*n)-i;
   for(int j=1;j<=stars;j++)
      {
        sop("*");
      }
   sopln();
}
