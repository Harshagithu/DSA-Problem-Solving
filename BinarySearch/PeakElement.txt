
Input :- arr = [1,2,3,4,5,8,3,2,1]

Output :- 5 (index position of 8 which greater than 5 in the left side and 3 in the right side)

Brute Force :-
==============

func(arr,n)
{
 if(n==1)return 0;
 if(arr[0]>arr[1])return 0;
 if(arr[n-1]>arr[n-2])return n-1;
 for(int i=1;i<n-1;i++)
 {
  if(arr[i]>arr[i-1]&&arr[i]>arr[i+1])
  {
    return i;
  }
 }
 return -1;
}

Time Complexity :- O(n)
Space Complexity :- O(1)


Optimal Approach :-
===================

func(arr,n)
{
 if(n==1)return 0;
 if(arr[0]>arr[1])return 0;
 if(arr[n-1]>arr[n-2])return n-1;
 int low=1,high=n-2;
 while(low<=high)
 {
  int mid=(low+high)/2;
  if(arr[mid]>arr[mid-1]&&arr[mid]>arr[mid+1])
  {
    return mid;
  }
  else if(arr[mid]>arr[mid-1])
  {
    low=mid+1;
  }
  else
  {
    high=mid-1;
  }
 }
 return -1;
}

Time Complexity :- O(log2n)
Space Complexity :- O(1)
