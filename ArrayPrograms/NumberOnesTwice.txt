
Input :- arr = [1,1,2,3,3,4,4]
Output :- 2

Brute Force :-
==============

func(arr,n)
{
   int maxi=arr[0];
   for(int i=0;i<n;i++)
   {
     maxi=Math.max(maxi,arr[i]);
   }
  for(int i=1;i<=maxi;i++)
  {
    int count=0;
    for(int j=0;j<n;j++)
    {
      if(arr[j]==i)
      {
        count++;
      }
    }
   if(count==1) return i;
 }
}

Time Complexity :- O(n^2)
Space Complexity :- O(1)

Better Approach :-
==================


func(arr,n)
{
   int maxi=arr[0];
   for(int i=0;i<n;i++)
   {
     maxi=Math.max(maxi,arr[i]);
   }
  int hash[]=new int[maxi];
  for(int i=0;i<n;i++)
  {
    hash[arr[i]-1]++;
  }
  for(int i=0;i<maxi;i++)
  {
    if(hash[i]==1) return i+1;
 }
}

Time Complexity :- O(3*n)
Space Complexity :- O(MaximumElement)

Optimal Approach :-
===================

func(arr,n)
{
 int xor=0;
 for(int i=0;i<n;i++)
 {
   xor^=arr[i];
 }
 return xor;
}

Time Complexity :- O(n)
Space Complexity :- O(1)
