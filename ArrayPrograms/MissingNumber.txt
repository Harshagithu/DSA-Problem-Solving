
Input :- [1,2,4,5] N=5
Output :- 3

Brute Force :-
==============

func(arr,n)
{
 for(int i=1;i<=n;i++)
 {
   int flag=0;
   for(int j=0;j<n-1;j++)
   {
     if(arr[i]==i)
     {
       flag=1;
       break;
     }
   }
  if(flag==0) return i;
 }
}

Time Complexity :- O(N^2)
Space Complexity :- O(1)

Optimal Approach :-
===================

func(arr,n)
{
  int ts=(n*(n+1))/2;
  int es=0;
  for(int i:arr)
  {
   es+=i;
  }
 return ts-es;
}

Time Complexity :- O(N)
Space Complexity :- O(1)
