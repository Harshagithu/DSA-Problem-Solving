
Input :- arr = [5,3,2,4,1]

Output :- 8 (for i<j where arr[i]>arr[j])

Brute Force :-
==============

func(arr,n)
{
 int count=0;
 for(int i=0;i<n;i++)
 {
  for(int j=i+1;j<n;j++)
  {
    if(arr[i]>arr[j])
    {
     count++;
    }
  }
}
return count;
}

Time Complexity :- O(n^2)
Space Complexity :- O(1)
