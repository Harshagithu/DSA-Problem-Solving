
Input :- arr = [1,2,0,3,0,0,4,5,2,3,3]
Output :- arr = [1,2,3,4,5,2,3,3,0,0,0]

Brute Force :-
==============

func(arr,n)
{
 ArrayList<Integer> temp=new ArrayList<>();
 for(int i=0;i<n;i++)
 {
   if(arr[i]!=0)
   {
     temp.add(arr[i]);
   }
 }
 for(int i=0;i<temp.size();i++)
 {
   arr[i]=temp.get(i);
 }
 for(int i=temp.size();i<n;i++)
 {
   arr[i]=0;
 }
}

Time Complexity :- O(n) + O(x) + O(n-x) = O(2n)
Space Complexity :- O(n)

Optimal Approach :-
===================

func(arr,n)
{
  int j=-1;
  for(int i=0;i<n;i++)
  {
    if(arr[i]==0)
    {
      j=i;
      break;
    }
  }
  if(j==-1) return;
  for(int i=j+1;i<n;i++)
  {
    if(arr[i]!=0)
    {
      swap(arr[i],arr[j]);
      j++;
    }
   }
}

Time Complexity :- O(x) + O(n-x) = O(n)
Space Complexity :- O(1)
