
Input :- [2,2,3,4,2,2]

Output :- 2

Brute Force :-
==============

func(arr,n)
{
 for(int i=0;i<n;i++)
 {
  int count=0;
  for(int j=0;j<n;j++)
  {
    if(arr[j]==arr[i]) count++;
  }
  if(count>n/2)
  {
    return arr[i];
  }
 }
 return -1;
}

Time Complexity :- O(n^2)
Space Complexity :- O(1)

Better Approach :-
==================

func(arr,n)
{
 Map<Integer,Integer> hm=new HashMap<>();
 for(int i=0;i<n;i++)
 {
  hm.put(arr[i],hm.getOrDefault(i,0)+1);
 }
 for(Map.Entry<Integer,Integer> entry:hm.entrySet())
 {
   if(entry.getValue()>n/2)
   {
     return entry.getKey();
   }
 }
 return -1;
}

Time Complexity :- O(2*n)
Space Complexity :- O(n)

Optimal Approach :-
===================

func(arr,n)
{
 int count=0,ele=0;
 for(int i=0;i<n;i++)
 {
  if(count==0)
  {
    ele=arr[i];
    count=1;
  }
  else if(ele==arr[i])
  {
    count++;
  }
 else
  {
   count--;
  }
}
return count>0?ele:-1;
}

This code illustrates the moore's voting algorithm where the result will decide based on the counter variable.

Time Complexity :- O(n)
Space Complexity :- O(1)
