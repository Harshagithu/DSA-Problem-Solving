

Input :- arr = [2,3,-2,4]

Output :- 6 [2,3]

Brute Force :-
==============

func(arr,n)
{
 int maxi=Integer.MIN_VALUE;
 for(int i=0;i<n;i++)
 {
  for(int j=i;j<n;j++)
  {
   int pro=1;
   for(int k=i;k<=j;k++)
   {
    pro = pro * arr[k];
   }
   maxi=Math.max(maxi,pro);
  }
 }
 return maxi;
}

Time Complexity :- O(n^3)
Space Complexity :- O(1)
