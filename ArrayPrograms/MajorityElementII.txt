
Input :- arr = [1,1,1,3,3,2,2,2] n=8

Output :- res = [1,2] (where 1 and 2 repeats more than floor of n/3 times which floor of 8/3 = 3)

Brute Force refer majority element.

Better approach refer majority element.

Optimal Approach :-
===================

func(arr,n)
{
 List<Integer> res=new ArrayList<Integer>();
 int cnt1=0,cnt2=0,ele1=Integer.MIN_VALUE,ele2=Integer.MIN_VALUE;
 for(int i=0;i<n;i++)
 {
   if(cnt1==0&&ele1!=arr[i])
   {
     ele1=arr[i];
     cnt1=1;
   }
   else if(cnt2==0&&ele2!=arr[i])
   {
     ele2=arr[i];
     cnt2=1;
   }
   else if(ele1==arr[i])
   {
     cnt1++;
   }
   else if(ele2==arr[i])
   {
     cnt2++;
   }
   else
   {
     cnt1--;
     cnt2--;
   }
 }
 if(ele1!=Integer.MIN_VALUE)
 {
   res.add(ele1);
 }
 if(ele2!=Integer.MIN_VALUE)
 {
  res.add(ele2);
 }
 return res;
}

Time Complexity :- O(n)
Space Complexity :- O(1)
